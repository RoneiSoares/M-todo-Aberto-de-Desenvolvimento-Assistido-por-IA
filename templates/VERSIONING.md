# Versionamento

## Estados

- **Em desenvolvimento:** sujeito a alteração/validação.
- **Candidata:** delimitada para avaliação.
- **Funcionalmente validada:** aprovada no ambiente real definido.
- **Tag:** referência Git imutável criada com autorização.
- **Release:** publicação baseada em tag aprovada.
- **GOLDEN:** referência comportamental confiável.

Build e smoke não tornam uma versão funcionalmente validada por si só.
