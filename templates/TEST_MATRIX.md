# Matriz de validação

| Versão | Build | Smoke/Lógico | Estrutural | Funcional | Aceitação |
|---|---|---|---|---|---|
| | | | | | |

## Regras

- Build confirma compilação.
- Smoke valida regras/caminhos limitados.
- Estrutural confirma composição/registro.
- Funcional confirma comportamento em ambiente real.
- Aceitação confirma adequação ao objetivo humano.
- Nenhuma evidência substitui silenciosamente outra.
