# Como contribuir

A proposta é aberta.

Contribuições úteis:
- contraexemplos;
- casos reais;
- simplificações;
- falhas encontradas;
- comparação com outros métodos;
- melhorias nos templates.

Formato recomendado:

`Problema → mudança proposta → motivo → exemplo real`

Evite:
- marketing;
- alegações de originalidade sem fonte;
- burocracia sem benefício;
- regra dependente de marca específica.
