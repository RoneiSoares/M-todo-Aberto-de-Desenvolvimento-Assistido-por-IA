# Como contribuir

Obrigado por ajudar a melhorar o Método Aberto de Desenvolvimento Assistido por IA.

A proposta está em estágio experimental. Por isso, críticas, contraexemplos e sugestões de simplificação são tão importantes quanto novas ideias.

## Formas de contribuir

Você pode:

- abrir uma Issue com dúvida, crítica ou proposta;
- relatar um caso real onde alguma regra funcionou ou falhou;
- propor alterações no texto por Pull Request;
- comparar o método com práticas já existentes;
- sugerir maneiras de reduzir burocracia;
- propor formas melhores de registrar evidências;
- discutir se GOLDEN deve ser obrigatório ou opcional;
- testar o método em outros domínios.

## Estrutura recomendada para propostas

Sempre que possível, descreva sua sugestão neste formato:

```text
Problema
→ mudança proposta
→ motivo
→ exemplo real
```

## O que valorizamos

Contribuições que tragam:

- exemplos reais;
- evidências;
- limitações observadas;
- contraexemplos;
- comparação com métodos existentes;
- propostas simples e aplicáveis.

## O que queremos evitar

- marketing vazio;
- alegações de originalidade sem evidência;
- aumento de burocracia sem benefício claro;
- regras dependentes de uma ferramenta específica;
- tratar build como prova suficiente de comportamento quando o contexto exigir validação adicional.

## Pull Requests

Pull Requests devem explicar:

1. qual problema está sendo resolvido;
2. qual parte do método muda;
3. por que a mudança melhora o método;
4. se há um caso real ou referência que sustente a proposta.

Mudanças grandes podem começar como Issue antes de virar PR.

## Discussão aberta

Discordar faz parte do processo.

O objetivo não é defender a versão atual, e sim descobrir quais princípios realmente sobrevivem ao uso em diferentes projetos.
