# 12 — Glossário

**Agente executor** — IA/ferramenta capaz de operar no repositório e ambiente.

**Branch** — linha isolada de desenvolvimento.

**Build** — processo de compilação/empacotamento.

**Commit** — registro versionado de alterações.

**Diff** — comparação entre estados/arquivos.

**GOLDEN** — referência funcional confiável usada para comparação.

**Issue** — registro de problema, tarefa ou discussão.

**Main** — branch oficial principal, quando o projeto usa esse nome.

**Merge** — integração de uma branch em outra.

**PR / Pull Request** — proposta de integração sujeita a revisão.

**Rebase** — reposicionamento de commits sobre outra base.

**Release** — publicação de uma versão.

**Remote** — repositório remoto.

**Smoke test** — teste básico/lógico de funcionamento limitado.

**Teste estrutural** — verificação de composição/registro/estrutura.

**Teste funcional** — execução do produto no ambiente real definido.

**Tag** — referência Git imutável nomeada.

**Worktree** — pasta adicional do mesmo repositório associada a outra branch.
